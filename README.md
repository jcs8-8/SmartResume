# SmartResume

## Project Overview

AI Resume & Portfolio Builder is a web application designed to help
students and job seekers create professional resumes and portfolios
using Artificial Intelligence.

## Problem Statement

Students often face difficulties creating professional resumes and
portfolios that effectively represent their skills, education, projects,
and experience.

## Objective

The objective of this project is to develop an AI-powered platform that
can generate and customize resumes and portfolios based on user-provided
information.

## Main Features

- User Registration and Login
- Student Profile
- Resume Builder
- Resume Templates
- AI-Generated Resume Content
- Job Description Analysis
- Resume Customization
- Portfolio Builder
- Portfolio Templates
- PDF Resume Generation
- Resume and Portfolio Preview
